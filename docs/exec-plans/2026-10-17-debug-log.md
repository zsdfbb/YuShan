    - `pub(crate) fn record(&mut self, ev: &'static str, ids: DebugIds<'_>, fields: Map<String, Value>)`：
      **先取时间与序号**（`dt_ms = start.elapsed().as_millis()`、`t_ms = run_start_unix_ms + dt_ms`、
      `seq = stats.seq.fetch_add(1, Relaxed)`），再拼信封、`serde_json::to_string` + `\n`、
      `try_send`；`Full` ⇒ `dropped += 1`，`Disconnected` ⇒ 静默丢弃；累计 `hot_path_ns`。

      同一 session 的 `/resume` 不调用（继续追加），`/new` 换会话时调用。
    - `pub(crate) fn begin_run(&mut self, run: u64, run_start_unix_ms: u64)`：`/resume` 后重置
      单调原点与 `run`（同一文件里新 run 以新 `run_start` 开头）。
    - `pub(crate) fn flush(&mut self, stop_reason: &str)`：发 `Command::Stop { stop_reason, ack }`；
      writer 排空队列后写 `run_end`（含 `debug{records_written,dropped,write_errors,bytes_written,hot_path_ms}`）
      再 ack；调用方 `recv_timeout(2s)`，超时放弃（best-effort）。
    - writer 线程：每行一次 `write_all`（预先拼好 `\n`）；连续 8 次 IO 错误停写；`bytes_written`

      `write`/`edit` 正文零字节；`webfetch` query `<redacted>`；`subagent` prompt 首行 256B；
      未知工具只留 keys + bytes。**UTF-8 边界收口**，总预算 512B（`full` 8 KiB）。
    - 脱敏：键名小写命中 `token/api_key/access_key/secret/password/authorization/cookie/credential/private_key`
      ⇒ 值替换为 `"[REDACTED]"`，键进 `redacted_keys`；**所有档位都生效，无关闭开关**。
    - 测试缝：`#[cfg(test)] fn open_with_writer<W: Write + Send + 'static>(...)` 允许注入慢 writer /
