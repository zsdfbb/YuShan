## 0. 全局约束（每个任务都适用）

1. **`toolset.rs` 零改动**（偏差 D5）：`EXPECTED_ORDER` / `vec!` / 3 处 `assert_eq!(tools.len(), 9)`
   一律不动。工具仍是 **9 个**，`Request` 仍是 **7 个变体**。
2. **零新依赖**：不引 `regex` / `globset` / `walkdir` / `serde_yaml` / `tempfile`。
3. **既有测试断言逐字锁死**：`prompt.rs::test_custom_prompt_takes_precedence`、
   `toolset.rs` 的 3 处 `len()==9`、`commands.rs::test_help_text_lists_every_command` 的**意图**不得放宽
   —— 若因新签名必须改调用，只改**调用形式**，不改**断言强度**。
4. **测试隔离**：临时目录名含 `进程内原子序号 + process::id()`；进程级 env 改写走 `crate::test_env::env_lock()`；
   优先用**显式 `&Path`**（`scan(roots)`）绕开 env。
5. **文档、注释、commit message 用中文**；代码标识符用英文。
6. 每个 impl 任务若未单列配对 test 任务，**测试写在同一任务内**，测试文件见该任务「涉及文件」列的括注。
