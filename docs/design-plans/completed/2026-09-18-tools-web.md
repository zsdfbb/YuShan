# tools-web（`websearch` / `webfetch`）设计计划

> 决策依据：`docs/arch/tools-web/design.md`（融合方案，**已整篇重写、无内部矛盾**）+ `review.md`（两轮 R1–R12 / N1–N13，全部处置）+ `docs/adr/0016-web-tools-design.md`。
> 本文不重新讨论取舍，只把既定设计落成可执行的任务划分。

## 背景

**当前状态**：coding agent 有 7 个工具（read/write/edit/bash/grep/find/ls），**全是本地的** —— 模型无法获取仓库外的信息（API 文档、报错含义、库用法）。

**为什么现在做**：设计链已闭环（context → design → review×2 → ADR）；**唯一的放行门槛已清** —— `htmd 0.5.x` 的 `skip_tags` 经官方 README 断言确认**移除整个子树**（`<script>x</script>` → `""`），`convert(&str) -> Result<String>` 整块输入，与设计一致。

**预期结果**：模型能搜网页；能把网页抓成 Markdown **落到本地文件**并 `read`/`grep` 它；且**调用链确定、降级行为可见**。

## 设计

**落点**：新 crate `adapters/tools-web`（8 个源文件）。`adapters/tools-basic` **保持无网络**（crate 边界强制）。

**与 app 的接缝**（唯一签名变化）：
```rust
pub fn build_tools(workspace: &Path, web: WebConfig) -> (Vec<Box<dyn Tool>>, Option<String>)
```

**六条承重约束**（细节见 `docs/arch/tools-web/design.md`）：
1. **落盘目录四档**（`YUSHAN_FETCHED_DIR` → `~/.yushan/fetched` → `temp_dir()/yushan-fetched-<pid>` → 不落盘）；解析结果是 `enum FetchedDir`（**带档位**）；**清理只对 `Primary` 生效**（用户给的 `Override` 只写不删）；**绝不产生相对路径**。
2. **落盘文件前 2 行**是警示 + Source URL，**且头算进 `head()` 计数** → `offset` 与文件行号 1:1 对齐、`read` 也可看到警示。
3. **链确定**：启动期构造一次并冻结；顺序只由 `const TABLE` 决定；**无动态选择、无并行竞速**；用了非第一顺位要在结果里明说。
4. **预算**：`CHAIN_BUDGET=30s` / `MIN_SLICE=8s` / `FETCH_BUDGET=30s` / `CONNECT_TIMEOUT=5s` / **不设 client 级总超时**；`remaining < MIN_SLICE` → 不试，否则 `slice = min(remaining, max(MIN_SLICE, remaining/left))`。
5. **降级只认错误/限额，空结果不降级**；全失败逐条列理由（与链同序）。
6. **SSRF 只作用于模型给的 URL，绝不作用于配置里的后端地址**（自建 SearXNG 常在 `127.0.0.1`）；`allow_loopback` 是构造参数，**没有任何 env 能打开**。

## 风险与注意事项

1. **`no_hint_when_both_backends_present`（`toolset.rs:223-235`）最易踩**：`assert_eq!(hint, None)` 会被 web hint 合并打破 → 测试必须改用**确定性 `WebConfig`**（`with_client`/`offline`），否则在无搜索配置的机器上必红。
2. **测试面很可能大于生产面**（SSRF 表 / 编码 / 预算切片 / 静默失败 / fixture 三态 / 假服务器护栏）—— 无 CI + 单人，**最需预留时间**。
3. **假服务器不能复用** `stream_usage_fallback.rs` 的 `MockServer`（文件内私有且**无超时**）→ 新写一份（脚本化应答 + delay + **超时护栏**）。
4. **`test_support` 跨 crate 不可见**（`#[cfg(test)] pub(crate)`）→ `tools-web` 的测试助手**照抄**（`test_dir`/`ctx`/`guarded`）。
5. **`htmd::convert` 返回 `Result`** —— 失败路径要有明确处置（倾向：`is_error` 结果 + notice，不静默返回原始 HTML）。
6. **工具数 7→9 每轮固定 +60~120 token** —— 净负外部性，已在 ADR 记录。
