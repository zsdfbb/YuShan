> 性质：**探索阶段的现状与约束**，不含方案选型。方案设计见后续 `arch-design` 产出。

## 概述

让 agent 能产出**可复现、口径自洽、可季度迭代**的公司研究文档（生意模式 + 护城河 + 巴芒框架评价 + 估值），而不依赖不稳定的联网检索。

## 现有架构

### 模块边界

本需求**不引入新 crate**。能力落在两处：

- **`bash` 工具**：一切取数与计算（`python3` + `akshare` + `pandas` 已就位）
- **skill**：研究骨架与口径纪律（当前 `skills/` 下 6 个 skill **全部是工程向**，无研究向骨架）

`webfetch` / `websearch` 只作补充，**不作主路径**（用户明确要求，且技术上也站不住，见「约束」）。

### 核心抽象（现状，非设计）

| 层 | 现状 |
|---|---|
| 取数 | `python3 -c` / heredoc 调 `akshare`，无封装 |
| 计算 | 同左；**无强制验算环节** |
| 落盘 | 无约定。文档直接由模型生成 Markdown |
| 待办台账 | `todo` 工具（`apps/coding-agent/src/toolset.rs:858`）管**当前任务**，不管报告内的 `[ ]` |
| 文档内 `[x]/[ ]` | 与正文、数据表**三方无对账机制** |

### 关键数据流（目标形态 vs 现状）

```
目标：  取数(akshare) → 落盘 CSV 快照 → 脚本算派生指标 → 口径校验 → 渲染 Markdown
现状：  ────────────────────────────────────────────────► 模型直接写 Markdown（数字手填）
```

**关键差异：现状没有任何落盘中间态**，因此每个数字都不可回溯，也无法被验算。

## 约束

- **技术**：不引新 crate（`docs/goals.md:165` 已定 `tools-finance` 无需求证据）；一切计算走 `bash` + `python3`。
- **技术**：`webfetch` **拒收 PDF**（`adapters/tools-web/src/fetch.rs:116`，PDF → `ContentKind::Binary`，不落盘）；上限 5 MiB / 30s。⇒ 财报 PDF 不能走 `webfetch`。
- **稳定性**：`websearch` 后端「各自配置才进链」（`adapters/tools-web/src/backends.rs:59-93`）；主路径不得依赖它。
- **节奏**：**季度一次**（用户确认）。季度迭代单元决定落盘形态必须可比对。
- **数据来源分工**（用户确认）：指数点位 / 基本信息**由券商手动获取**；财报季度分析走程序取数 + PDF 补充。
- **口径**：同一张表里 `营业总收入` 与 `营业收入` 是**两个口径**（茅台 26Q3 差 23.13 亿），派生指标必须登记分子分母与报告期。

## 需求范围

### 范围内

- 季度公司研究文档的可复现生成流程（取数 → 快照 → 验算 → 渲染）
- 估值专项：DCF（反向）、PE/PB、股息率、历史分位
- 巴芒框架的结构化载体（芒格五标准 / 巴菲特标尺 / 容错率），避免每次即兴重述
- 文档内待办与正文、数据快照的对账

### 范围外（明确不做）

| 不做 | 理由 |
|---|---|
| `tools-finance` crate | 取数已由 akshare 完成，crate 只重复一遍（`docs/goals.md:165`） |
| 自建 PDF 解析器 | 结构化数据已覆盖；表格只需 `pdfplumber` 一条 pip |
| `DisplayTool` / ECharts 报告 | 目标文档形态是 Markdown 表格，非 HTML（`docs/arch/etf-display-tool/` 的需求未被采纳） |
| 指数 / 基本信息自动化 | 用户从券商手动取，落成手工快照即可解耦网络 |
| 输出单一目标价 | DCF 终值占比实测 **82.3%**，单点不可证伪（见下） |
| 基金 / 债券 / 宏观 | 无需求证据 |

## 现状问题：目标文档的实测缺陷

以下不是猜测，是 2026-11-12 对 `茅台生意模式与巴芒理论评价.md` 逐项复算的结果：

| # | 位置 | 文中 | 实算 | 性质 |
|---|---|---|---|---|
| 1 | 摘要 L7 | 目标价 +22.9% 空间 | 1953/1410.27 = **+38.5%**（正文 L441 自己写的 +38.5%） | 前后矛盾 |
| 2 | 1.3 表 | CFO/净利(TTM) 约 130.7% | 1073.84/644.67 = **166.6%**；130.7% 是配 2025 年报净利 823.20 | **分母换期** |
| 3 | 1.3 结论 3 | FCFE 占净利约 40% | 339.88/644.67 = **52.7%**；且 `339.88` 在 akshare 中**无对应公式**（OCF−CapEx = 826 亿，差 2.43 倍） | 口径不明 |
| 4 | 1.9 / 7.2 表 | 五粮液、可口可乐整行 `—` | 横向对比结论仍成立 | 空数据被引用 |
| 5 | 十、待办 | `[x]` 补充完整财务数据 2021-2026Q3 | 实为 6 行年报，2019/2020 缺失 | 台账脱节 |

**#2 是典型 TTM 分子配年报分母**，人眼几乎抓不住，`python3` 一秒抓住。⇒ 验算环节的价值有现成的验收样本。

### DCF 的实测敏感性（同一家公司）

参数：rf = 1.6032%（10Y 国债实测）、ERP 5%、WACC ≈ Ke = 6.60%、FCF₀ = 1050 亿（OCF TTM 1073.84 − CapEx 约 20）、市值 17629.53 亿、FCF 收益率 **5.96%**。

| g \ WACC | 5.5% | 6.6% | 7.6% | 8.6% |
|---|---|---|---|---|
| 1.5% | +62% | +27% | +6% | −9% |
| 2.0% | +82% | **+38%** | +13% | −4% |
| 2.5% | +108% | **+52%** | +22% | +2% |
| 3.0% | +145% | +70% | +33% | +10% |

- **基准点（WACC 6.6%, g 2.5%）终值占 82.3%** ⇒ 结论由终值主导，单点必然不可证伪。
- 结论在「低估 62%」到「高估 9%」之间摆动，全部落在合理参数范围。
- ⇒ DCF 只能用作**反向估值**（「现价隐含什么」），不能用来「算目标价」。

### 历史估值分位（实测）

`stock_zh_valuation_baidu` PE(TTM) 614 点：当前 **21.46**，历史分位 **30.3%**（最小 8.95 / 中位 27.70 / 最大 94.77）。文档称「不足 30% 分位」，量级相符。

## 后续建议

- 建议用 `arch-design` 做方案设计，候选至少包含「纯 skill」与「skill + 落盘约定」两种形态。
