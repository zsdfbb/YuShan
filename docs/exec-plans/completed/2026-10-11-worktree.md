## 任务清单

### Task 1: `apps/coding-agent/src/worktree.rs` — worktree 核心模块 [type=impl]

- **涉及目录**: `apps/coding-agent/src/`
- **涉及文件**: `apps/coding-agent/src/worktree.rs`（新增）
- **描述**: 全仓唯一 git 调用点。含：
  - `WorktreeError { NotARepo, GitUnavailable, InvalidName(String), NotFound(String), Git(String) }`
  - `worktrees_dir()` —— `YUSHAN_WORKTREES_DIR` 覆盖，否则 `$HOME/.yushan/worktrees/`
  - `main_repo(cwd) -> Result<RepoInfo>` —— 用 `git rev-parse --git-common-dir` 的**父目录**取主仓根与名
    （**不是** `--show-toplevel`：在树内运行会返回树根）
  - `path_for(repo, name)` —— `name` 校验（非空、无 `/` `\`、非 `.`/`..`）+ HOME 相对路径前缀拼接
  - `auto_name()` —— 复用 `wiring::new_session_id()` 的时间戳形态（零新依赖、零碰撞）
  - `create(repo, Option<&str>)` —— `git worktree add -b worktree-<name> <path> HEAD`；**捕获子进程输出**；
    建软链 `<path>/.yushan` → 主仓 `.yushan`（无则跳过）；同名陈旧 registration ⇒ `git worktree prune` 重试一次
  - `list(repo)` —— `git worktree list --porcelain` 筛出 ys 目录下的条目 + `dirty`（`git status --porcelain`）
  - `remove(repo, name)` —— `git worktree remove <path>`；**透传 git 拒删原因**
  - `attach_target(cwd, name) -> Result<PathBuf, WorktreeError>`（工作区，单一返回值）
- **关联测试任务**: Task 2
- **依赖**: 无

### Task 3: `apps/coding-agent/src/main.rs` — CLI 接线 [type=impl]

- **涉及目录**: `apps/coding-agent/src/`
- **涉及文件**: `apps/coding-agent/src/main.rs`
- **描述**:
  - `Args` 加 `worktree: Option<WorktreeCmd>`；新增 `enum WorktreeCmd { Create(Option<String>), Attach(Option<String>), List, Remove(String) }`
  - `parse_args` match 首 token 加 `"worktree"` 臂（**纯增量**，不扰动既有 `_ =>` 静默 Interactive 行为）
  - `main()` 在 `Config::from_env()`(:1207) 后、skill 扫描(:1224) 前分流：
    `Create`/`List`/`Remove` 执行后**早退**；`Attach` ⇒ `worktree::attach_target()` 成功后 `config.cwd = 树路径`，
    失败 ⇒ 响亮警告 + 保持 cwd 不变继续启动
  - 抽 `worktree_exit_line(...)`，在 **两个**既有退出打印点（`main.rs:801` `persist_single_turn`、
    `main.rs:1194` TUI 退出后）各追加一行
- **关联测试任务**: Task 4
- **依赖**: Task 1
