三份文档（合 1100+ 行）里的指标词频统计：

| ROE | 31 | 卖空比例 | 11 |

## 1. 第 0 层：元数据（七列，强制）

**这一层比任何业务数据都重要。** 现有文档的五处硬错误全部源于缺这一层，而非缺数据：

| 字段 | 含义 | 缺失时的实际后果 |
|---|---|---|
| `as_of` | 快照时点 | 「行情截至 2026-11-12」散落在正文，无法自动校验是否为最新 |
| `period_type` | `cumulative` / `quarterly` / `ttm` | 1073.84/**644.67** 标成 TTM，实为配 823.20 年报 ⇒ 写 130.7%，实为 **166.6%** |
| `stat_kind` | `point`（时点）/ `period`（期间） | 资产负债表项是时点值，利润表是期间值，混用即错 |
| `unit` | 亿元 / 港元 / 元 / % / 倍 | 农夫山泉全文港元，茅台人民币；跨公司对比时会静默串味 |
| `source` | 出处（接口名 / 研报名 / 公告日） | 「339.88 亿 FCFE」无任何可回溯来源 |
| `status` | `ok` / `missing` / `estimated` | 可比公司表整行 `—`，结论仍写「PE 低于农夫山泉」 |
| `stat_scope` | `consolidated` / `parent` | 归母 vs 合并口径 |

**硬规则：七列不全的数据不入库。** 季度迭代的整个价值建立在「可对账」上，缺列即无法对账。

## 2. P0 · 行情与估值序列（日频，回溯 ≥10 年）

| 数据项 | 粒度 | 对应文档引用 |
|---|---|---|
| 收盘价 — **未复权** | 日 | 1.7 年度股价轨迹、52周区间 |
| 收盘价 — **前复权** | 日 | 5 年年化、区间涨跌幅 |
| 总市值 / 流通市值 | 日 | 「总市值 17629.53 亿」、隐含股本校验 |
| **PE(TTM) 时间序列** | 日 | 历史分位（把「假设 PE 25 倍」换成分布） |
| **PB 时间序列** | 日 | 同上 |
| **股息率时间序列** | 日 | 「股息率 3.69% 比农夫山泉高 1.21pct」 |
| 成交额 / 换手率 / 振幅 | 日 | 流动性、「慢牛而非抢筹」判断 |

**为什么必须存时间序列而非当前值**：文档 7.2 节那张「PE 18/20/22/25/30 倍 → 对应股价」的表是**假设推演**，不可证伪。有序列才能改写成「当前分位 30.3%（614 点，2001 起，中位 27.70）」，从假设变成事实。

**52周高低、年内涨跌、N 年年化 → 由上述数据派生，不采集。**

### 覆盖范围的三类差异

| 类别 | 标的 | 字段差异 |
|---|---|---|

## 3. P0 · 三张财务报表（季度，**累计与单季双存**）

**只存一个口径必然出错。** 单季 = 本期累计 − 上期累计，必须同时落成两列，`period_type` 分别标注。

### 3.1 利润表

| 字段 | 备注 |
|---|---|
| 营业总收入 | **必须与「营业收入」分开存** |
| 营业收入 | 茅台 26Q3 两者差 **23.13 亿**，混用即错 |
| 营业成本 | 算毛利率用 |
| 销售 / 管理 / 研发 / 财务费用 | 期间费用率 |
| 营业利润 / 利润总额 / 所得税 | 税负与营业利润率 |
| 净利润 | 含少数股东 |
| **归母净利润** | 文档全篇基准 |
| 扣非归母净利润 | 判断利润质量 |
| 少数股东损益 | 校验净利润与归母差额 |

### 3.2 资产负债表（`stat_kind = point`）

总资产、总负债、**存货**（茅台核心变量）、应收账款、货币资金、有息负债（短期借款+长期借款+应付债券）、归母净资产、股本

### 3.3 现金流量表

| 字段 | 备注 |
|---|---|
| 经营活动现金流净额 | 文档 22 次引用 |
| **购建固定资产等支付的现金（CapEx）** | 算 FCF 必需，**缺它就只能编数** |
| 折旧与摊销 | EBITDA 口径 |
| 投资 / 筹资活动净额 | 现金流结构 |

**回溯要求 ≥10 年**：文档需要「5 年年化」「历史首次负增长」判断，现有 6 行年报不足以支撑。

## 4. P0 · 派生指标（脚本计算，不采集）

ROE（加权 / 摊薄 / 平均三口径）、ROIC、ROA、毛利率、净利率、期间费用率、资产负债率、流动比率、速动比率、存货周转率与天数、应收周转率与天数、FCF（OCF − CapEx）、FCF 收益率、分红率、股息率

**关键约束：派生指标必须存「分子值 + 分母值 + 报告期」三件套，只存结果即埋雷。** 文档 1.3 节的错误正是只存了结果（130.7%），没存分母是哪个期。

---

## 5. P1 · 结构数据（护城河论证的成立依据）

| 数据 | 粒度 | 对应文档论证 |
|---|---|---|
| **分产品收入 / 成本 / 毛利率** | 半年报、年报 | 茅台酒 vs 系列酒；农夫山泉 水/茶/果汁 |
| **分地区收入**（境内 / 境外） | 半年报、年报 | 「海外收入占比未获取，待补充」这个 [ ] |
| 分渠道收入（直销 / 经销） | 半年报、年报 | 「直销占比过半」——**最关键，也最可能接口没有** |
| 产能 / 产量 / 销量 / 库存量 | 年报 | 「以产定销」「五年基酒周期」 |

---

## 6. P1 · 分红与股东回报（按方案，回溯 ≥10 年）

每股现金分红、分红总额、分红率、股息率、股权登记日、除权除息日、方案进度（预案/实施）、**特别分红标记**、分红次数

**特别分红必须单独标记**：茅台 2022、2023 有特别分红，不标记会让「分红率趋势」算出错误斜率。

---

## 7. P2 · 市场资金面（日频，**窗口定义必须写死**）

主力净流入（1 / 3 / 5 / 10 / 20 / 60 日，**每个窗口单独成列**）、主力流入率、**卖空比例**、南向 / 北向持股与净买卖、融资余额

⚠️ 这组在文档中出现 28 次（卖空 11、主力 10、南向 7），但**是全篇最不可验证的数据**。必须带 `窗口定义 + 数据商`；拿不到就标 `estimated`，不得进结论。

---

## 8. P2 · 经营高频数据（财报接口基本没有，需独立来源）

批价（飞天散瓶 / 整箱）、动销、渠道库存周期、i茅台投放量与成交价、高端白酒月度产量、经销商数量

文档 17 次引用（批价 6、i茅台 6、动销 5）。**这是传统财报接口覆盖不到的**，须单独定来源策略，不要混进主流程。

---

## 9. P2 · 文本类（落原始件，不做结构化）

| 类型 | 保留字段 | 用途 |
|---|---|---|
| 研报 | 机构、分析师、发布日期、评级、目标价、**原文全文** | 目标价区间（文档 7 处引用） |
| 公司公告 | 公告日、类型、原文 | 分红方案、渠道改革 |
| 业绩说明会 / 电话会纪要 | 日期、原文 | 管理层表述变化对比 |

**聚合值（如「机构平均目标价」）由脚本从原文计算，不采集聚合结果**——否则又是一个黑箱口径。

## 10. 优先级与验收

| 级别 | 内容 | 缺了会怎样 |
|---|---|---|
| **P0** | 第 0 层七列元数据 + 三张报表（累计&单季）+ PE/PB 历史序列 + CapEx | 季度迭代退化成「重新写一遍」 |
| **P1** | 分红方案（含特别分红）、分产品/分地区、产能产销量 | 护城河论证失去数据支撑，只能靠断言 |
| **P2** | 分渠道、资金面、ETF 专项、高频经营数据 | 可标 `missing` 降级，不阻塞 |
| **P3** | 研报文本、公告原文 | 独立来源，异步补 |

**验收标准（用已知缺陷做样本）**：拿茅台一期数据重跑，下列五处应被自动拦下——

1. 摘要 +22.9% 与正文 +38.5% 矛盾（1953/1410.27 = +38.5%）
2. CFO/净利标 TTM 却用了年报分母（130.7% → 166.6%）
3. FCFE 339.88 亿无来源、与 OCF−CapEx 826 亿差 2.43 倍
4. 可比公司表整行 `—` 仍被结论引用
5. 待办 `[x]` 与正文数据范围不符

## 11. 建议不采集

| 不采 | 理由 |
|---|---|
| 复权因子单独存 | 直接存未复权 + 前复权两份即可，省掉复权口径打架 |
| 分钟线 / 逐笔 / Level2 | 用途是季度研究，无回测需求 |
| 分析师预测的聚合值 | 只存原文，聚合由脚本算，避免黑箱口径 |
| 实时推送 | 季度节奏，日频收盘价足够 |

---

## 12. 唯一必须提前定的事

**分渠道（直销/经销）与批价动销**两处，接口大概率给不了，但结论又依赖它。

建议现在就明确：拿不到时**标 `missing` 并在正文显式降级**，而不是留一行 `—` 之后继续下结论——现有文档第 4 条缺陷就是这么来的。
